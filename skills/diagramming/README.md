# Diagramming

Skills for turning ideas and code into diagrams.

## Model-invoked

Rich trigger phrasing so the agent can reach for them automatically (also usable on request).

- **[whiteboard](./whiteboard)** — Turn natural language into hand-drawn `.excalidraw` diagrams (sketches, flowcharts, architecture, ER/UML/sequence, mind maps) via a Python `Scene` builder; export PNG/SVG locally; or auto-layout a codebase's import/class graph. Opens in excalidraw.com, the VS Code Excalidraw extension, and Obsidian.
